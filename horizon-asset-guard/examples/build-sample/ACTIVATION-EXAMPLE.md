# Activation example

What the seller sends the buyer after `hag issue`, for this sample package. The buyer of this
package pressed Play in world `123` and sent the request code `HAG-REQ-demo-123-QK42` (the
console line `[AssetGuard] I01 no license, trial mode. Activation request code: HAG-REQ-demo-123-QK42`);
the seller ran:

```
hag issue --sku demo --buyer b001 --req HAG-REQ-demo-123-QK42
```

The license is signed with the public demo key (`examples/demo-keys/`), so it proves nothing
and works only with the `GuardData_*.ts` files in this folder (they were encrypted under the
same buyer key). It is bound to world 123: in any other world the console prints `E12` and a
fresh request code. The whole sample is regenerated by `node examples/make-build-sample.mjs`.

- The license only works in the world id(s) above. If you duplicate the world or move the game to another world, press Play there, copy the new `HAG-REQ-...` code from the console and send it to me for a free re-issue (up to 4 of your own worlds per license).

- Until the license is in place the game runs in trial mode: everything works, but with the trial data tables.
